# 🍔 Podrão Chique

## 📌 Sobre o projeto

O **Podrão Chique** é um projeto de desenvolvimento web que consiste na criação de um site para uma lanchonete, utilizando **HTML5 e CSS3**.

O objetivo é apresentar a lanchonete aos clientes, divulgar seus produtos, apresentar preços e promoções, disponibilizar informações sobre o estabelecimento e oferecer páginas para realização de pedidos e contato.

O projeto foi desenvolvido como atividade acadêmica, com o propósito de colocar em prática os conhecimentos adquiridos em desenvolvimento web.

## 🚀 Tecnologias utilizadas

- **HTML5:** utilizado para estruturar o conteúdo e as páginas do site.
- **CSS3:** utilizado para estilizar os elementos, organizar os layouts, definir cores, fontes e posicionamento das imagens.

## 📄 Páginas do projeto

O site possui 12 páginas HTML:

| Página | Descrição |
|---|---|
| Início | Apresentação da lanchonete. |
| Cardápio principal | Apresentação geral dos produtos. |
| Lanches caseiros | Exibição dos tipos de lanches disponíveis. |
| Bebidas e acompanhamentos | Lista de bebidas e acompanhamentos. |
| Promoções e combos | Divulgação de ofertas e combinações de produtos. |
| Sobre nós | História e apresentação da lanchonete. |
| Localização | Informações sobre onde encontrar o estabelecimento. |
| Galeria de fotos | Exibição de imagens da lanchonete e dos produtos. |
| Pedidos | Formulário para preenchimento de pedidos. |
| Pedido enviado | Página de confirmação do pedido. |
| Contatos | Informações e formulário de contato. |
| Comentário enviado | Página de confirmação do envio de comentário. |

## 🎯 Objetivos de aprendizagem

Durante o desenvolvimento deste projeto, foram trabalhados conceitos importantes de desenvolvimento web:

- Estruturação de páginas com HTML.
- Criação e utilização de folhas de estilo externas com CSS.
- Organização de arquivos em pastas.
- Utilização de imagens e elementos visuais.
- Criação de menus e navegação entre páginas.
- Utilização de formulários.
- Organização e estilização de conteúdos.
- Utilização do Git e GitHub para versionamento e armazenamento do projeto.

## ▶️ Como visualizar o projeto

1. Faça o download ou clone deste repositório.
2. Extraia os arquivos, caso tenha baixado o projeto em ZIP.
3. Abra a pasta `projeto final`.
4. Entre na pasta `html`.
5. Abra o arquivo `pagina1_inicio.html` em um navegador.
